Карточка файла

Формат, имя, размер; активна кнопка «Проанализировать»

Анализ

Чтение → извлечение текста → анализ (таймер) → отчёт. Можно остановить

Отчёт

Последовательно заполняются 4 блока результатов

Действия

Фильтр замечаний, скачать отчёт, проверить другой документ

02Интерактивная демонстрация

Визуальная модель интерфейса: две колонки — загрузка слева, результаты справа. Файл никуда не отправляется, показывается пример отчёта. Нажмите на строку статистики, чтобы отфильтровать замечания.
